## 1. 产品概述

针对国内初中生"小四门"（政治/道法、历史、地理、生物）刷题训练的竖屏移动应用，采用微信小程序视觉风格的 Web App。包含客户端（学生刷题学习）和管理端（用户与题库管理）两个系统，帮助学生系统化备考中考。

- **目标用户**：国内初中生（六年级至九年级，含五四学制）
- **核心价值**：覆盖多版本教材（人教、鲁科、统编、湘教等几十种版本），按年级/学科/版本精准刷题，配合学情看板实现可视化学习闭环

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 学生（客户端用户） | 手机号/账号注册 | 刷题、收藏、查看学情、模拟考试 |
| 管理员（管理端用户） | 后台账号分配 | 用户管理、题库管理、数据统计 |

### 2.2 功能模块

**客户端（4个底部导航Tab）：**
1. **首页**：毛笔字"中考必胜"标题、横屏轮播图、年级选择（含坚持学习天数/今日答题数/正确率三信息展示）、学科学习入口
2. **备考冲刺**：毛笔字标题、学霸笔记滚动新闻板、超级考点速记（收藏/已掌握/未掌握数量）、全真模拟考试、真题考试与预复习资料库
3. **学情看板**：毛笔字标题、今日学习时长与错题率、每周学情柱状图、综合掌握百分比与排名、错题本/成绩单/收藏题目
4. **我的**：个人信息展示与设置

**管理端：**
1. **用户管理**：用户列表、增删改查、学习数据查看
2. **题库管理**：题目增删改查、按版本/学科分类
3. **数据统计**：用户活跃度、题目使用情况

## 3. 核心流程

### 3.1 学生刷题学习流程
用户打开应用 → 进入首页 → 选择年级 → 查看学习概况（天数/答题数/正确率）→ 选择学科与教材版本 → 进入刷题 → 答题判分 → 收藏错题 → 学情看板查看统计

### 3.2 备考冲刺流程
进入备考冲刺 → 浏览学霸笔记滚动信息 → 查看考点速记统计 → 选择全真模拟/真题考试 → 考试答题 → 出分 → 错题归集

### 3.3 管理端流程
管理员登录 → 用户管理（增删改查）→ 题库管理（录入题目）→ 数据统计查看

## 4. 用户界面设计

### 4.1 设计风格

**核心美学方向：新中式墨韵·考运主题**
将传统中国书法、水墨意境与现代移动端交互融合，营造"考运亨通、金榜题名"的仪式感与学习专注感。

- **主色调**：
  - 宣纸米白 `#F5EFE0`（背景主色）
  - 墨黑 `#1A1A1A`（主文字）
  - 朱砂红 `#C8332C`（强调色，"中考必胜"印章感）
  - 青竹绿 `#3A6B4C`（学科标签、正确状态）
  - 古铜金 `#B8893D`（勋章、成就装饰）
- **毛笔字标题**：使用"马善政毛笔楷书"或"霞鹜文楷"等书法字体，左上角竖排或横排呈现"中考必胜"，带印章红
- **字体**：标题用书法字体，正文用"思源宋体"或"Noto Serif SC"，数字用"DM Serif Display"
- **布局风格**：竖屏移动端，卡片式布局，错落排版，顶部毛笔字+印章，底部Tab栏
- **视觉细节**：水墨晕染背景纹理、印章红点缀、古籍纸张质感、朱红描边按钮
- **图标风格**：线性中式图标，配合少量传统纹样装饰

### 4.3 响应式设计

- **移动优先（竖屏）**：客户端按 375px 宽度设计，最大 430px 居中，桌面端两侧留墨韵装饰背景
- **管理端**：桌面优先，最小宽度 1024px，表格自适应
- **触摸优化**：按钮最小44px触控区，底部Tab栏安全区适配

### 4.4 系统切换

- 入口页：选择"客户端"或"管理端"，墨韵风格两个大卡片入口
- 客户端：移动端竖屏布局
- 管理端：桌面端后台布局
